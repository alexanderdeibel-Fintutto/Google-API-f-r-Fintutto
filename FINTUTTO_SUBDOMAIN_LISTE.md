## STRATO DNS-KONFIGURATION

Für jede Subdomain bei Strato:

1. **Login** → Strato Kundenbereich
2. **Domains** → DNS-Verwaltung → fintutto.de
3. **Subdomain anlegen** (z.B. `rechner-rendite`)
4. **CNAME-Record setzen:**
   ```
   CNAME: [subdomain] → [gamma-url].gamma.site
   ```
   ODER
   **A-Record** (je nach Gamma-Anweisung)

### Gamma-Seite Verknüpfen:

1. Öffne das Gamma-Doc
2. Teilen → Einstellungen → "Veröffentlichung und..."
3. "Domain hinzufügen" → z.B. `rechner-rendite.fintutto.de`
4. Gamma zeigt DNS-Einstellungen → bei Strato eintragen
5. Warten (1-24h) → SSL wird automatisch aktiviert
